# Rofl: Instant Windows Shutdown ⚡️

Небольшая утилита, написанная на **Kotlin/Native**, которая осуществляет мгновенное выключение компьютера под управлением Windows.

## 🛠 Как это работает

Программа использует низкоуровневый (и недокументированный) API Windows для форсированного завершения работы:

1. Запрашивает привилегию `SeShutdownPrivilege` для текущего процесса.
2. Загружает библиотеку `ntdll.dll`.
3. Находит и вызывает функцию `NtShutdownSystem(2)`, что приводит к аппаратному отключению питания (Power Off) в обход стандартного цикла завершения работы приложений.

## ⚠️ ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ

**Используйте с осторожностью!** Эта программа **не** закрывает приложения корректно и **не** предлагает сохранить открытые документы. Запуск приведет к немедленному выключению системы, что может повлечь за собой **потерю несохраненных данных**. 

Проект создан исключительно в образовательных целях, чтобы продемонстрировать возможности взаимодействия Kotlin/Native с Windows API (Win32 API).

## 🚀 Сборка и запуск

Для компиляции потребуется установленный JDK и Gradle. Проект настроен на сборку под платформу `mingwX64`.

Скомпилировать исполняемый файл можно стандартной задачей Gradle для Kotlin/Native:
```powershell
./gradlew linkReleaseExecutableMingw
```
После успешной сборки `.exe` файл можно будет найти в директории `build/bin/mingw/releaseExecutable/`.

---
*Если после запуска вы видите в консоли надпись «Если вы это видите, значит выключение сорвалось.», значит у программы не хватило прав для выключения компьютера.*
